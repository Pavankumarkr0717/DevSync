# Benchmarks

No benchmarks have been run yet, and DevSync makes **no** throughput, latency, user-count, cost or
reliability claims (constitution Principle XII).

Every benchmark added here MUST include:

1. **Question**: what is being measured, and why.
2. **Environment**: hardware, OS, runtime and dependency versions, data volume.
3. **Method**: tool, workload, warm-up, duration, number of runs.
4. **Commands/scripts**: exact steps to reproduce, committed alongside the results.
5. **Results**: raw numbers plus a summary with variance, not just a headline figure.
6. **Limits**: what the result does *not* show.

Use one folder per benchmark: `docs/benchmarks/YYYY-MM-DD-short-name/`.
